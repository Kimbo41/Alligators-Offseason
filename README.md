# Leonberg Alligators – Offseason Team-Plan

Trainingsplan mit Trainingslog für die Offseason der Leonberg Alligators (American Football).
24 Wochen in 3 Phasen · 3 Einheiten pro Woche · Phase 1: Legoman Powerbuilding 1 & 2

**Zur Seite:** https://kimbo41.github.io/Alligators-Offseason/

## Für Spieler: So geht's

1. Link oben in **Safari** (iPhone) bzw. **Chrome** (Android) öffnen.
2. **Zum Home-Bildschirm hinzufügen**
   - iPhone: Teilen-Symbol → „Zum Home-Bildschirm“
   - Android: Menü (⋮) → „Zum Startbildschirm hinzufügen“
3. Beim ersten Start einmalig **Name, Trikotnummer und Position** eintragen.
4. Ab dann immer über das Alligators-Symbol öffnen.

## Wochenplan

| Tag | Einheit |
|---|---|
| Montag | Lower Body – Strong Hips / Strong Legs (wöchentlich im Wechsel) |
| Donnerstag | Upper Body – Push it / Pull it (wöchentlich im Wechsel) |
| Samstag | Kraftzirkel oder Cardio |

Phase 1 (Woche 1–8): Woche 1–4 Legoman Powerbuilding 1 · Woche 5–8 Legoman Powerbuilding 2
Phase 2 (Woche 9–16) und Phase 3 (Woche 17–24) folgen. Die Phase wird im Profil ausgewählt.

## Funktionen

- Pro Satz Gewicht und Wiederholungen eintragen und abhaken. Das letzte Gewicht wird vorgeschlagen.
- Notiz pro Übung, Körperbefinden (1–5) und Notiz nach jeder Einheit
- Video-Link zu jeder Übung
- Verlauf mit Wochenübersicht, Volumen, Körperbefinden und geschätztem 1RM der Mainlifts
- **CSV-Export**, um das Log an die Coaches zu schicken
- Funktioniert auch offline im Studio

## Datenschutz

Alle Einträge werden **nur auf dem eigenen Handy** gespeichert. Es gibt keine Anmeldung und keinen Server.
Die Coaches sehen die Daten nur, wenn der Spieler die CSV-Datei selbst verschickt.

**Tipp:** Schick deine CSV einmal pro Woche an die Coaches. Das ist gleichzeitig deine Sicherung, falls du das Handy wechselst.

## Für Coaches: Seite aktualisieren

1. Neue `index.html` hochladen (Add file → Upload files) und die alte überschreiben.
2. In `sw.js` die Versionsnummer in der ersten Code-Zeile erhöhen (`v1` → `v2`), damit die Handys die neue Version laden.

Die Einträge der Spieler bleiben bei Updates erhalten.
